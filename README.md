# Projet 11/12 de la formation intégrateur web (OpenClassRooms), par Natasha Finkelsztajn.

## Description : 
Implémentation du front-end d'une application (React.js et Redux) et écriture de routes HTTP en adéquation avec le back-end (fourni).  

## Installation  
1. Clonez le projet :  
```sh
git clone https://github.com/NatashaFinkel/P-11-version-2.git
```

2. Installez les dépendances
```sh
cd my-app
npm install
```

3. Lancez le projet !
```sh
npm run dev
```

## Fonctionnalités : 
- L'utilisateur peut visiter la page d'accueil.
- L'utilisateur peut se connecter au système (et pouvoir gérer des erreurs si l’username ou mdp sont incorrects).
- L'utilisateur peut se déconnecter du système.
- L'utilisateur ne peut voir les informations relatives à son propre profil qu'après s'être connecté avec succès.
- L’utilisateur ne peut pas modifier son nom ni son prénom, mais il peut modifier son pseudo.

## Compétences visées:
- Afficher des données du back end sur une interface via des appels API
- Configurer des routes API pour la communication client / serveur
- Implémenter la gestion des données avec Redux pour assurer le fonctionnement du front
- Implémentation du front-end selon le cahier des charges
- Green Code

## Outils utilisés :
- React.js
- Redux, Redux Toolkit
- React router
- Create React App
- node.js (côté serveur)
- Swagger, méthode HTTP
